# Hamza Portfolio — Cinematic Hero

A hero-only React + Vite + TypeScript + Tailwind CSS v4 build using shadcn/ui-style source components and GSAP.

## Run

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Current scope

- Fullscreen looping background video
- Cinematic editorial typography
- Liquid-glass navigation and CTA
- GSAP intro choreography
- Subtle pointer-responsive depth on fine pointers
- Reduced-motion behavior
- Responsive mobile composition
- HERO only — no other portfolio sections yet
